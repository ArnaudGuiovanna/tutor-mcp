02 The learning engine →

Tutor MCP.
Run it where you choose.

Keep a local learning profile or host a shared service. One server binary, six platform builds. Tutor MCP is separate from the desktop app and the language model.

On a Mac, choose ARM64 for an Apple M-series chip or x64 for Intel. Windows ARM64 and Linux ARM64 downloads here are server builds.

Or use the Linux / macOS installer.

Download and inspect the script, then run it as your normal user. It detects the machine’s architecture, checks SHA-256 and installs the licence notices.

Terminal
curl -fsSL https://raw.githubusercontent.com/ArnaudGuiovanna/tutor-mcp/v0.7.0/scripts/install.sh -o install-tutor.sh
TUTOR_MCP_VERSION=v0.7.0 TUTOR_MCP_INSTALL_DIR="$HOME/.local/bin" sh install-tutor.sh
"$HOME/.local/bin/tutor-mcp" --version

Expected: tutor-mcp v0.7.0. Then connect your local client or deploy an institution.
