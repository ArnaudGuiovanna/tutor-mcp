Install Tutor ACP on Windows

Install the app, connect your AI agent and join your learning community.

01

What you need

Tutor ACP is the desktop app. Tutor MCP is the learning service that stores programmes, progress and session memory. Your institution can provide that service, or you can install it on your own computer.

  • A Windows x64 computer. This release distributes the desktop app for Windows x64.
  • Access to Codex or Claude through the provider account or authentication method offered by your agent. Provider access and any associated costs are separate from Tutor.
  • For an institution, its HTTPS address and an administrator who can authorise your public identity.

The app includes the Codex and Claude adapters and their Node.js runtime. You can use these bundled agents without installing Codex Desktop, npm or Node.js separately. Advanced Windows and WSL2 setups remain available in Settings.

02

1. Install the Windows app

Download Tutor ACP 0.0.1 for Windows x64, run the installer and open Tutor. The downloads page lists the current packages and checksums.

The desktop app and the server have separate version numbers. Tutor ACP 0.0.1 is distributed in the Tutor MCP v0.7.0 release. Older technical client previews remain available in the release history.

If your organisation controls software installation, use its normal approval process. The release includes checksums for verifying the downloaded files.

03

2. Connect Codex or Claude

  1. Open Settings → Agents.
  2. Select the bundled Codex or Claude agent and connect it.
  3. When sign-in is requested, choose the method offered by that agent and complete the provider’s authentication flow.

The provider connection and the Tutor connection are separate. A successful AI sign-in does not automatically grant access to an institution.

The bundled agents already have a private working folder. Keep the advanced adapter and executable fields at their defaults for the standard installation.

04

3. Create and back up your Tutor identity

  1. Open your account and find Your local identity.
  2. Create an identity, choose a backup passphrase and save the encrypted backup separately from your computer.
  3. Wait until the identity is marked Backed up.
  4. Give your institution’s administrator the two public npub values shown by the app: your identity and its recovery identity.

The administrator authorises these public identities. Your private keys and backup passphrase stay with you. The passphrase protects the backup file; it is not an institution login password.

Keep the backup file and its passphrase in separate safe places. See backups and updates before replacing a device or recovering an account.

05

4. Connect to your institution

  1. Open Settings → Institution and select Institution or remote server.
  2. Enter the institution’s HTTPS origin, such as https://tutor.example.org. Use the address without /mcp.
  3. Select Verify institution and check the name and address returned by the service.
  4. Once your public identities have been authorised, select Connect with my account.

The institution connection uses your local identity. Account creation by email and an institution password are not part of this native connection.

06

5. Check that you are ready to learn

Both the agent and Tutor should show a successful connection. Open Courses to browse the programmes available to your account. If your institution allows personal programmes, you can also start directly in Conversation.

Your first message
I want to learn Go. Help me choose a realistic goal and guide me through a first 20-minute session.

Follow the first-session guide to choose a course, record your work and resume it later. A message marked Ready to send is kept while setup is incomplete and resumes once the required connections are ready.

For a personal local setup, follow Install Tutor on your computer instead of the institution identity steps.
