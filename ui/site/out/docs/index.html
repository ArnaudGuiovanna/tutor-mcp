Get going

Quick start

Two paths. For a learning community, install the Windows client and connect it to your institution. For yourself, install the binary and let your MCP client start it.

i.Get the binary

Installer for Linux, macOS and Windows, or go build .

ii.Pick a profile

--local on your machine, hobby on a VPS, institution on PostgreSQL.

iii.Connect your AI

Add tutor-mcp --local to your client, or your VPS /mcp URL with OAuth.

iv.Start learning

“Use Tutor MCP to help me learn Go.” Resume later from the same installation.

Learning community? Install Tutor ACP 0.0.1 for Windows x64. Codex and Claude adapters are included; your institution provides the Tutor service. See Tutor ACP.
Get going

What you need

BinariesLinux, macOS and Windows, amd64 and arm64, with SHA256SUMS on the release page.
From sourceGit and Go 1.26.10 or a newer patched release. One module, pure-Go SQLite, no CGO.
LocalNothing else. No account, no HTTP server, no WSL, Docker or SMTP.
Hobby VPSA DNS name, inbound TCP 80 and 443 for Caddy, SSH for administration. SQLite.
InstitutionPostgreSQL with sslmode=verify-full, separate API, worker and migrator processes, operator-managed keys, an HTTPS proxy.
Tutor ACPWindows x64. Bundled Codex and Claude adapters with their Node.js runtime; native or an explicitly chosen WSL2 distribution.

Hosted assistants such as Claude on the web, ChatGPT and Le Chat need a public HTTPS endpoint with a trusted certificate. Local clients such as Claude Code, Claude Desktop, Hermes and Gemini CLI run the binary over stdio.

Get going

How it works

Tutor MCP sits between the assistant and the learner state. The assistant stays the conversational interface; Tutor MCP is the memory and decision runtime.

1You talk to your AI

Ask for a goal, a review, a harder challenge or a session close, in natural language.

2The AI calls MCP tools

It reads learner context, asks for the next activity with get_next_activity, records outcomes with record_interaction, closes the session.

3Tutor MCP updates state

BKT estimates, FSRS-5 review timing, prerequisite access, assessment evidence, narrative memory and decision snapshots.

Learning engineVersioned concept graph, goals, interactions, mastery estimates, review dates, assessment and transfer evidence. Chooses a phase, concept and activity with explicit rules.
Narrative memoryStable learner notes, pending observations, concept notes, session summaries and consolidated archives. Encrypted and versioned in the database.

The important split: the AI writes explanations and summaries, but Tutor MCP owns the state transitions and the next-activity decision. Narrative text cannot promote itself into assessment evidence. Full details in the architecture and algorithm guides.

Install

Install the binary

Linux and macOS

Download the installer from the repository, inspect it, then run it. It selects your platform, verifies the archive against SHA256SUMS and keeps licence notices beside the executable.

$ curl -fsSL https://raw.githubusercontent.com/ArnaudGuiovanna/tutor-mcp/main/scripts/install.sh -o install-tutor.sh
$ TUTOR_MCP_VERSION=v0.7.0 TUTOR_MCP_INSTALL_DIR="$HOME/.local/bin" sh install-tutor.sh

Add $HOME/.local/bin to your PATH and restart your MCP client. Without TUTOR_MCP_INSTALL_DIR, the installer uses /usr/local/bin and may ask for sudo.

Windows

Download install.ps1, inspect it, then run it from PowerShell as your normal user. It verifies SHA-256, installs under %LOCALAPPDATA%\Programs\tutor-mcp and adds that directory to your PATH.

PS> .\install.ps1 -Version v0.7.0

From source

$ git clone --branch main https://github.com/ArnaudGuiovanna/tutor-mcp.git
$ cd tutor-mcp
$ go build .

This creates tutor-mcp (tutor-mcp.exe on Windows). Keep its full path for your client configuration. Pin a tagged release in production; the installation guide covers notices, checksums and upgrades.

Install

Tutor ACP for Windows

Tutor ACP 0.0.1 for Windows x64 is the desktop client for learning communities. It connects Codex or Claude to your institution’s Tutor service over the Agent Client Protocol.

  1. Install the client. Codex Desktop is not required: the bundled adapters and their Node.js runtime are included.
  2. In Settings → Agents, select Codex or Claude and connect your provider account. Provider access and costs are separate from Tutor.
  3. In Settings → Institution, enter your institution’s address and connect with an authorised Tutor identity. The client generates the identity and a distinct recovery key locally; export the encrypted backup and keep it offline.
  4. Open Formations to choose a programme from the catalogue, or write what you want to learn in Conversation when your institution allows personal programmes.

The client offers French and English, light, dark and system themes and reading settings saved per account. MCP tool permissions can be remembered across conversations for the selected account, server and agent. The server controls access and progress. See the desktop client guide for identities, backups, native Windows and WSL2.

Install

Local profile

Your MCP client starts tutor-mcp --local and talks to it over stdin and stdout. No HTTP server, JWT or SMTP. Your learning profile lives in ~/.tutor-mcp/local; add --data-dir for another private directory. Several local clients can share the same profile and learner identity.

Claude Desktop and other mcpServers clients

Open Settings → Developer → Edit Config, merge this into the configuration and restart the client. Replace command with the full path if the binary is not on PATH; on Windows, use a path such as C:/tools/tutor-mcp.exe.

{
  "mcpServers": {
    "tutor": { "command": "tutor-mcp", "args": ["--local"] }
  }
}

Hermes

mcp_servers:
  tutor:
    command: tutor-mcp
    args: ["--local"]

Gemini CLI, Pi and others

Gemini CLI uses the same command/args shape. Pi delegates MCP to extensions: configure yours to launch tutor-mcp --local. Any client that speaks stdio MCP works. See the client guide.

Install

Hobby VPS

One HTTP server for a personal VPS or a small group. SQLite, username and password accounts, invitations over SSH. Choose a DNS name, point it at the VPS and allow TCP 80 and 443 for Caddy. Only Caddy is public; Tutor listens on 127.0.0.1:3000.

Native: binary, systemd and Caddy

$ sudo useradd --system --home-dir /var/lib/tutor-mcp --shell /usr/sbin/nologin tutor
$ sudo install -d -m 0700 -o tutor -g tutor /var/lib/tutor-mcp
$ sudo -u tutor /usr/local/bin/tutor-mcp init --profile hobby \
    --data-dir /var/lib/tutor-mcp/hobby --public-url https://tutor.example.org
$ sudo install -m 0644 deploy/tutor-hobby.service /etc/systemd/system/tutor-hobby.service
$ sudo systemctl daemon-reload && sudo systemctl enable --now tutor-hobby

init creates the configuration, the encryption key and the signing key, then prints an account invitation valid for 24 hours. Keep it private and open it once HTTPS is ready. Install Caddyfile.native with your domain, then validate and reload:

$ sudo caddy validate --config /etc/caddy/Caddyfile
$ sudo systemctl reload caddy
$ curl --fail https://tutor.example.org/ready

Your MCP URL is https://tutor.example.org/mcp. Administration runs over SSH as the service user:

$ sudo -u tutor tutor-mcp users invite --data-dir /var/lib/tutor-mcp/hobby
$ sudo -u tutor tutor-mcp users list --data-dir /var/lib/tutor-mcp/hobby
$ sudo -u tutor tutor-mcp users reset alice --data-dir /var/lib/tutor-mcp/hobby
$ sudo -u tutor tutor-mcp users disable alice --data-dir /var/lib/tutor-mcp/hobby

Docker Compose

$ export TUTOR_DOMAIN=tutor.example.org TUTOR_VERSION=v0.7.0
$ docker compose -f deploy/compose.hobby.yml build
$ docker compose -f deploy/compose.hobby.yml run --rm --no-deps tutor \
    init --profile hobby --data-dir /data/hobby --public-url "https://$TUTOR_DOMAIN"
$ docker compose -f deploy/compose.hobby.yml up -d
$ curl --fail "https://$TUTOR_DOMAIN/ready"

Keep the three named volumes across upgrades and never upgrade with down --volumes. Details, including trusted proxy ranges, in the installation guide.

Install

Institution

--profile institution serves a learning community: a shared catalogue, member access, contribution review and individual learning paths. Members need no email address or server password. The Windows client generates a public-key identity and a distinct recovery key; the server stores public keys only.

  • PostgreSQL with sslmode=verify-full, forced row-level security and separate tutor_api, tutor_worker and tutor_restore roles. Reapply deploy/postgres-roles.sql after every schema upgrade.
  • Three processes: run the migrator once, then enable the stateless API and the worker. systemd units and a Compose file are provided in deploy/.
  • Operator bootstrap: tutor-control-plane creates the plan and the tenant, then binds the owner’s two public keys. Set INSTITUTION_ID on the API so the client discovers the institution at /.well-known/tutor-institution.
  • Members are added from their own public keys with roles such as learner, admin, pedagogy_manager, trainer or auditor. An unknown key cannot self-register.

Follow the institutional setup and operations guide for keys, backups, tenant restoration, SLOs and erasure.

Connect

Claude Code

Add a user-scoped stdio server:

$ claude mcp add --transport stdio --scope user tutor -- tutor-mcp --local

Or put the mcpServers JSON above in the project’s .mcp.json and approve that server in Claude Code. For a VPS, use your https://your.domain/mcp URL instead.

Connect

Remote connectors

Install a hobby or institution profile and expose https://your.domain/mcp with a publicly trusted certificate. The client discovers the authorization server, registers or resolves its client metadata and opens the sign-in and consent flow. PKCE, resource binding and refresh-token rotation protect the session.

Claude on the web
  1. Settings → Connectors → add.
  2. Name: Tutor MCP. Server URL: https://your.domain/mcp.
  3. Add, then complete the OAuth sign-in.
ChatGPT
  1. Settings → Connectors → Advanced → Developer mode.
  2. Create: name Tutor MCP, your /mcp URL.
  3. Create and authenticate via OAuth.
Le Chat
  1. Connectors → Add Connector → Custom MCP.
  2. Name tutor_mcp, your /mcp URL.
  3. Connect, complete OAuth.
Gemini

Gemini CLI connects over stdio or httpUrl. Gemini Enterprise registers the service as a custom MCP data store through its administrator setup.

Hobby accounts use an operator invitation and a username and password; institutional accounts use the client’s public-key identity. Operators can restrict dynamic client registration; see OAuth registration.

Verify

Test your setup

Send this in a fresh conversation. Tutor also exposes a tutor_mcp prompt for clients that support MCP prompts.

Use Tutor MCP to help me learn Go for backend development. Find out what I already know,
create a learning plan, and guide me through a first 20-minute session. Save my progress when we finish.
  • The assistant calls get_learner_context, then init_domain or get_next_activity.
  • You see a reply that names a concept, a phase and a first activity.
  • After an answer, record_interaction is called. Without it, nothing updates.

In Tutor ACP, the Conversation page shows each tool call as it happens, and the programme is saved from the first exchange. Next time: “Resume my Go learning with Tutor MCP.”

Operate

Learner memory

Tutor keeps two layers. The learning engine stores structured state: domains, interactions, BKT and FSRS values, calibration, affect, assessment evidence and scheduler data. Narrative memory keeps what numbers cannot express; the AI writes it through MCP and reads it back on the next activity.

SessionsSummaries with affect, concepts touched, salient exchanges and next-step commitments.
Concept notesCurrent narrative state per concept, updated when a durable observation appears.
Stable memoryLearner preferences and durable facts, promoted only when confirmed or explicitly stated.
PendingUnconfirmed hypotheses, exposed as such so the AI does not treat them as established.
ArchivesMonthly, quarterly and annual consolidation written by the connected AI.

The main tools are record_session_close, update_learner_memory, read_raw_session and get_memory_state. In the three profiles, narrative objects are encrypted, versioned database records; the key material in keys.json is generated before the database and must be restored with it. Your AI provider still hosts its own chat transcript. See memory operations.

Operate

Backup and restore

For local and hobby profiles, stop every process using the profile, then copy the entire directory, including runtime.db, any WAL and SHM files and keys.json, to a private destination. Restore the database and the keys together, under the service’s operating-system owner, then restart with the same profile.

$ systemctl stop tutor-hobby
$ cp -a /var/lib/tutor-mcp/hobby /private/backups/tutor-hobby-$(date -u +%FT%TZ)
$ systemctl start tutor-hobby

Never copy only the main file of an open WAL database. Backups contain secrets and must stay private. Institutions keep their PostgreSQL procedures, separate server-key backups and the tenant restore runbook; members keep their own encrypted identity backups. A backup you have never restored is a backup you do not have.

When things go sideways

Troubleshooting

The assistant never calls the tutor

Name the runtime explicitly: “Use Tutor MCP.” Plain conversation does not update the learning record. If the client lists the server but no tools appear, check the executable path and restart the client.

Tutor ACP keeps the message as “À envoyer”

Setup is incomplete. Finish the agent connection in Settings → Agents and the institution connection in Settings → Institution; the message is sent once both are ready.

Remote OAuth fails

The certificate must be publicly trusted: curl --fail https://your.domain/ready should succeed without warnings. Check TRUSTED_PROXY_CIDRS and that the public Host header reaches Tutor. Account creation alone does not grant client access; the account must authorize the client.

A local installation refuses to start

Its keys.json is missing or invalid. Restore the original key with the database instead of generating a replacement.

Need more? Open an issue, start a discussion, or read OPERATIONS.md. For vulnerabilities, use private reporting, never a public issue.
